## Commercial release gate

Before official/business publication, replace these photos with owner-authorized originals or obtain photographer licenses. Record photographer, original source file, permission document, permitted uses, attribution, release/consent requirements, capture date, cropping/focal points and owner sign-off. Review identifiable people, license plates and prominent third-party marks. Then revise visible source notes and metadata only with explicit approval. `scripts/build.py --production` refuses the current configuration.
